The commit (`a327a217`) and the test's own comment both claim:

Root cause: `TestComposerCensusScopeLineOnlyAppearsWithRows`'s first assertion builds
`plates` from one held-but-unassigned hashlock material, which yields exactly one plate
with `path == 0`. `composerPreimageCensusLines` has an EARLIER guard —
`if len(plates) == 1 && plates[0].path == 0 { return []string{"", composerCopyPreimageOnlyNotice()} }`
(the pre-existing stand-alone-notice form) — that returns before the mutated region is ever
reached, textually and at runtime, regardless of where inside the normal path the scope-line
append sits. So the named mutation is dead on arrival for this test: it can never be
exercised by the fixture chosen.

The gap is real and reachable, not just a test artifact: built a probe with TWO held
hashlock materials neither assigned to any path (`len(plates) == 2`, both `path == 0`),
which skips both early returns and has `len(accepted) == 0`. On the ORIGINAL (unmutated)
code this correctly omits the scope line; on the mutated code:

```
census:
This engraves 0 plates.
Each plate takes minutes to cut. Have that many blanks ready before you start: a set is only a backup when all of it exists.

md1 and mk1 plates carry error correction. A plain descriptor plate carries only its checksum, which finds a mistake but cannot fix one.

This is what this composition will cut. Plates cut in earlier runs are not known to this device and are not listed.
preimage bddf2d8a..bc59e8a9: not on any path, will not be cut
preimage f20a0890..94165eb9: not on any path, will not be cut
--- FAIL: TestZZZProbeTwoUnassignedPlates (0.00s)
```

i.e. the mutation produces exactly the failure mode F-497 exists to prevent — a scope line
("This is what this composition will cut") sitting over a census that lists zero cut plates
— and nothing in the shipped test suite would catch it. This is both (a) a false claim in
the commit/test comment ("this fails" — it does not) and (b) an uncovered reachable case
(two-or-more held, all-unassigned-or-declined preimages with zero accepted rows).

Mutation reverted; tree confirmed clean (`git status --porcelain` empty) before continuing.

Severity: **Critical** — per the brief's own severity list, "a test that cannot fail on
what it names" and "a false claim in either commit message" are both named Critical
classes, and this finding is exactly that class.
