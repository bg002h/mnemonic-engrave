## Recovery, import and delivery

### C1 · Critical · A partially keyed wallet gets a checklist that omits the missing cosigner keys

`bundle::run_bundle`, `crates/me-cli/src/bundle.rs` (both `keyless_template |= !d.is_wallet_policy()` sites), at lines 429 and 464, and `Manifest::checklist` in `manifest.rs:129`. The pinned md-codec predicate becomes true with **one** embedded xpub. A 2-of-3 descriptor can therefore be counted without telling the holder that two other xpubs must be preserved. Losing those xpubs can prevent reconstructing even the first receive address.

Pipe these three lines to `me bundle`. They are a complete, checksum-valid md1 chunk set for the repository's public BlueWallet multisig fixture with only slot 0 populated.

```text
md1fuxc8pqpqjtvyyy4qqxppcgsc97v95zqyudm486mm4xav6hqp2s2xmaqxt5geqytgq3qzcgp
md1fuxc8pqd8qusvtqm68p540u75vz7l8qx4jqmze5e0xt2pyq94xcuqr4yu55s6euxplsp0f06
md1fuxc8pqsh35nuevya8z62kep2q7md6duvfx8px8yg8ygdjvlt5pterqqfv3wmpxkymn5c
```

Observed exit 0, `key_slots=3`, `keyless_template=false`, `wallet_plates=4` including the ms1 reminder, and “backup needs 3 public plates, plus one ms1 plate per seed you hold”. The pinned derivation returned `MissingPubkey { idx: 1 }`. Restoring all three public entries made address 0 derivable. Removing all three triggered the existing template warning. F-602 addressed the zero-key case.

**Fix and regression.** For each decoded policy, compare its required slots with the indices in its pubkey TLV. Name the missing slots and their separate recovery material in the checklist and JSON. When a supplied mk1 cannot be bound to the slot, leave that requirement explicit. Keep the count of supplied physical plates distinct from a claim of recoverability. Test zero, one and three embedded keys in this same fixture and require the warning for exactly the missing keys.

### I1 · Important · A seed that satisfies `--expect mnemonic` can be unrecognizable on the device

`me sysw pack`, `sysw::classify_with` at `crates/me-cli/src/sysw/mod.rs:362`. Take eleven `abandon` words followed by `about`. Join them with single ASCII spaces, then replace only the first separator with two spaces. Pipe it to `me sysw pack --no-passphrase --expect mnemonic`. The ordinary fixture exited 0 and the device classified the delivered record as `ClassMnemonic` (1). With two spaces, the command again exited 0, preserved both spaces in a 146-byte container, and the device returned `ClassUnknown` (0). A tab and a nonbreaking space gave the same discrepancy. A holder can pass the explicit backup check and carry a record the seed flow cannot use.

**Fix and regression.** Require the device-enterable canonical single-space spelling when admitting a mnemonic to the wire, with a diagnostic that identifies the separator problem. Keep the broad recognition needed for protecting secret input on public channels. Exercise the three whitespace variations and the canonical control through the CLI and the Go classifier. This is a systemwide counterpart of the earlier whitespace fix for `me seal`.

### I2 · Important · The same JSON wallet export selects different spending quorums on host and device

`me sysw pack --as descriptor|md1`, `descriptor/cascade.rs:887` (`parse_json`). Use `jq -n --arg a "$A" --arg b "$B" '{descriptor:$a, Descriptor:$b}'` to produce the file. Pipe it to `me sysw pack --no-passphrase --as descriptor`, then repeat with `--as md1`. Both succeeded with A's 2-of-3 policy and first address `bc1q4taqq6q6l8fvguva6ftvrz3qgdjy6p3w2s0ds0nl6qrjw7t0hfhqgrqcwd`. The pinned Go `nonstandard.OutputDescriptor` on the same bytes returned B's **1-of-3**. The B-only host control produced `bc1qukaxuksf05mswl9zpwcc4y2k8atux7pggf0udukz754heyk79vpqv6hn9d`. Reversing the fields made Go choose A. Rust chooses the exact lowercase field in either order. The ambiguity affects both the spending rule and the paying address.

**Fix and regression.** Detect conflicting case-insensitive descriptor members while reading the object, before `serde_json::Value` collapses duplicate exact names. Refuse the ambiguity before address display or output. Preserve a single mixed-case field. Test both field orders, an exact duplicate key with conflicting values, and the two single-descriptor controls through both output forms. Record the deliberate admission rule in §4.4 of the descriptor spec when implementing it.

### I3 · Important · An option before the subcommand can silently switch the input or destination

`me` argument dispatch, `crates/me-cli/src/main.rs:20` and `:675`. Write `text:6162` to `given`. Run `printf 'text:6364\n' | me --in given sysw pack --no-passphrase --out before.bin`. Exit 0, bytes after the 52-byte header are **`text:6364`**. Put `--in given` after `pack` and the record becomes **`text:6162`**. Likewise `me --out missing.bin sysw pack --no-passphrase text:6869` with stdout captured exited 0, created no named file and sent the container to stdout. These are converter options accepted by the top-level parser and discarded in subcommand dispatch. The October mixed-record-input fix acts later.

**Fix and regression.** Make explicit converter options conflict with selecting a subcommand, for example using clap's argument/subcommand conflict setting at the root. Keep the pre-parse secret guard's ordering. Test both option placements with different records in file and stdin, and test a misplaced output option with a previously absent destination. The ambiguous calls should refuse before reading or writing.

### I4 · Important · Raw stdout delivery can report success after the destination rejects every byte

`me --stdout` in `main.rs:845` (raw stdout branch near the end of `run`), and `me sysw pack` in `main.rs:3317` (`emit`). In a private directory, the following Linux probe returned **0**, wrote a zero-byte regular file and printed a digest followed by the reprint instruction. Without the size limit it wrote 61 bytes. The converter on `D` normally wrote 32 bytes and likewise exited 0 with zero bytes under the limit.

```python
import os, resource, signal, subprocess
def limit(n):
    signal.signal(signal.SIGXFSZ, signal.SIG_IGN)
    resource.setrlimit(resource.RLIMIT_FSIZE, (n, n))
os.umask(0o077)
with open("sink.bin", "wb") as sink:
    r = subprocess.run(["me", "sysw", "pack", "--no-passphrase", "text:6869"],
                       stdout=sink, preexec_fn=lambda: limit(0))
print(r.returncode, os.stat("sink.bin").st_size)
```

The small raw payload fits Rust's stdout buffer. `write_all` succeeds there and the flush error is lost at exit. A 65,536-byte zeros wipe under the same limit correctly exited 2. The newline-terminated hex converter went the other way, panicking at exit 101 when printing failed.

**Fix and regression.** Hold a stdout lock, propagate both `write_all` and `flush` errors through the existing I/O exit, then print the success card. Use checked writes for text modes too. Test an error only at flush and the regular-file probe above, checking for absent success diagnostics. Keep the large-write control.

### I5 · Important · A failed named-file replacement destroys a valid previous backup

`mnemonic_io_lib::write::write_private`, `crates/mnemonic-io-lib/src/write.rs:47`, reached by converter, manifest, seal and sysw file outputs. Create `old.bin` with `me sysw pack --no-passphrase --out old.bin text:6162` (61 bytes). Use the Python `limit` above with 8, and run `me sysw pack --no-passphrase --out old.bin text:6364`. Exit 2, but the old artifact now consisted of eight bytes, `MNEMSYSW`. The October fix protects a failed chmod. This failure happens after chmod and truncation have succeeded.

**Fix and regression.** For regular-file replacement, write and finish a 0600 temporary file in the destination directory before renaming it over the previous artifact. Keep intentional FIFO delivery and the existing permission-denied behavior. Seed the destination with a valid container and require byte-for-byte preservation, no partial destination or leftover temporary file, and a successful retry. Retain the existing shrinking-overwrite and FIFO tests.

### I6 · Important · The public packer changes one validated document into multiple unusable records

`sysw::pack` / `pack_with`, `crates/me-cli/src/sysw/mod.rs:553` and `:624`, and `split_records` at `:736`. Use the `input` field of `formats-happy/bluewallet-sh-fixture`, trimmed, as a **single** member of the library's input vector. `sysw::classify(doc)` returned `Descriptor`. `sysw::pack(vec![doc.into()], None, wire::MIN_ITERATIONS)` succeeded. `open` on its bytes returned **14 public records, all Unknown**. The ordinary CLI `--as descriptor` conversion produces one canonical descriptor. A public-API caller can lose both the record boundaries and the recovery semantics without receiving an error.

**Fix and regression.** Make the packer's serialized-record contract explicit. Refuse embedded CR/LF before section assembly or canonicalize a supported complete descriptor through the existing descriptor conversion before joining. Keep the CLI's whole-document import working. Test this fixture through pack/open and require either an actionable refusal or one usable descriptor. Also check a wrapped mnemonic passed as one argv record with `--allow-argv-secret --expect mnemonic`. It currently emits two unknown records after a successful expectation check.

### I7 · Important · The public region-image builder turns a truncated container into a full-length image

`sysw::region_image` at `crates/me-cli/src/sysw/mod.rs:694`. Pack `["text:6869"]` with no passphrase, remove its last byte and call `region_image(&blob[..60])`. `open` correctly refused the short input with `TooShort(60)`. The image builder returned `Ok` with 65,536 bytes. Opening that image failed with `NotUtf8` because padding occupied the missing record byte. The original 61-byte container produced a readable padded image. A consumer can mistake a padded, unusable backup for a completed flash image.

**Fix and regression.** After header parsing and before allocation, require `blob.len() >= h.total_len()`, using the existing short-input error. Preserve support for complete padded inputs. Test a missing public byte, a missing authentication-tag byte, and the complete control. The CLI's ordinary pack path constructs its input internally.

### I8 · Important · Inspection reports success and an identity for an unreadable public section

`me sysw show`, `main.rs:2011` (Show arm), `:2114` and `:2321`. Make a normal `text:6162` container. Change the final byte of the **serialized record** to `0xff` without changing the length. The original produced a record listing and digest. The changed file exited 0, printed header fields and a 64-digit identity, emitted empty stderr, and silently omitted both records and digest. A caller testing inspection success has no indication the public records could not be read.

**Fix and regression.** Validate the bounded public section as UTF-8 once before presenting the successful inspection and pass that slice to both printers. Report a format error at exit 4 for malformed bytes. Keep unknown but well-formed future records inspectable. Test a one-byte encoding error, a valid file, and a sealed file whose public section is empty.

### I9 · Important · Record admission accepts text and passphrase bodies that cannot decode as text

`sysw::classify_with` at `sysw/mod.rs:339`, `sysw::record::decode_text` at `sysw/record.rs:173`, and `me sysw pack`. Pipe `text:ff`, then `pass:ff`, separately to `me sysw pack --no-passphrase`. Each exited 0 and wrote 59 bytes. The outer record is valid ASCII in both cases. The classified bodies (`FreeText` and `Passphrase`) each return `NotUtf8` from the public text decoder. `text:c3a9` packs and decodes to “é”. §5.3.1 of the systemwide spec defines the body of these two records as UTF-8.

**Fix and regression.** Validate decoded UTF-8 during admission of these two prefixes. Keep the `tx:` decoder byte-oriented. Extend the shared record-class vectors with both invalid bodies and the valid multibyte control, and assert CLI refusal before any container or success card. I8 operates at a different layer and needs its own test.

### I10 · Important · The manifest can overwrite a preview that the command reports as rendered

`me bundle`, `main.rs:885–899`. With a matching sidecar and empty directory `p`, run `printf '%s' "$D" | me bundle --preview p --manifest p/plate-1.svg`. Exit 0. The manifest names the first preview and stderr reports the render, but `plate-1.svg` starts with JSON and is the manifest itself. The same happens with `--png` and `p/plate-1.png`. With distinct paths the Go renderer produces the expected image.

**Fix and regression.** Compare the manifest destination with all planned plate destinations before invoking the sidecar. Resolve equivalent parent paths and account for existing aliases. Refuse a conflict before creating any artifacts. Check both formats, an equivalent path through `./`, and a distinct manifest whose referenced files decode as images.

### I11 · Important · The printed digest recovery command fails for a filename with spaces

`me sysw pack`, `main.rs:2083`. Run `me sysw pack --no-passphrase --out 'my copy.bin' text:6162`. The file is valid. The printed instruction is `me sysw show my copy.bin`. Executing it exits 2 with “unexpected argument 'copy.bin'”. The quoted command exits 0 and prints `1ad5 a49b 17a1 2dbb 7ba1 093b e9cf 09bb`. This is the operator's printed route back to the comparison digest.

**Fix and regression.** Render the path as one shell argument, with an option terminator before it where needed. Run the emitted command in the supported shell and compare its digest for paths containing a space, an apostrophe and a leading dash. Apply the same quoting rule wherever another emitted command interpolates a path.

### I12 · Important · The mt1 vector generator can certify itself without its independent reference corpus

`scripts/gen-mt1-vectors.py:228–258`, `--self-test` and the pre-generation check. Run `python3 scripts/gen-mt1-vectors.py --self-test --mk-vectors nowhere.json` with no such file. Exit 0 and “SELF-TEST PASSED”, after skipping both the independent corpus and HRP check. With just the first string from the committed mk corpus in `{"vectors":[{"expected":{"strings":[STRING]}}]}`, it again passed, reporting 0 regular, 1 long and omitting the HRP check. With the complete corpus it verified 40/40 (19 regular, 21 long) and ran the HRP check. A standalone clone lacks the developer-specific default corpus path.

**Fix and regression.** Make the independent corpus portable or require an explicit path. Require each pinned string to verify exactly once, coverage of both checksum families and an executed HRP check. If advertising verification against the committed corpus, also pin its identity or expected membership. Test missing, single-family and complete corpora. Failed validation must exit nonzero before modifying either generated file.

### I13 · Important · The documented vector-generation command overwrites both goldens with an empty corpus

### I14 · Important · The demo build publishes a stale emulator when an embedded asset changes

`demo/sh2/build.sh:16–29`, reached by `FORK=... bash demo/sh2/build.sh`. The freshness test considers Go sources and module files. The pinned emulator embeds `cmd/emu/sysw_test_payload.bin` in `sysw_test_payload.go:58`. In a private copy of the demo, point `FORK` to a fixture with a small Go main under `cmd/emu` that imports `_ "embed"`, embeds that filename into a string and calls `println` on it. Give it the emulator's three build inputs (`build.sh` running `GOOS=js GOARCH=wasm go build -o emu.wasm .`, `index.html`, `wasm_exec.js`) and a Go module. Test two successive demo assemblies with an embedded-only edit and assert the embedded bytes in the second distributed WASM. ### I15 · Important · An out-of-range unhardened origin is silently converted to a different, hardened path

`me sysw pack --as descriptor`, `descriptor/cascade.rs:1138` (`parse_path_element`). In `A`, replace just the first `/48h/` with `/2147483696/` and pipe the result to `me sysw pack --no-passphrase --as descriptor`. The latter value is 2³¹ + 48 and has no hardening marker. Exit 0. The entire emitted container was byte-identical to the ordinary `/48h/` control. The host thus records origin metadata different from the operator's spelling without reporting invalid input. The related `sh-parsepath-unhardened-overflow` entry in FOLLOWUPS is filed against the Go fork. This is the Rust host counterpart.

**Fix and regression.** Check that the numerical component is below 2³¹ before applying any hardening marker. Exercise both descriptor import output forms, the valid boundary 2147483647, the invalid unhardened boundary 2147483648 and the ordinary explicitly hardened control. Check for refusal before creating an output file.

### I17 · Important · Validating a trimmed card then writing the original leaves a noncanonical card in the backup

**Previously filed, F-245.** `me sysw pack` and `sysw::pack`. `seal/record.rs:144` validates the trimmed value, and `sysw/mod.rs:624` joins the original strings. Run `me sysw pack --no-passphrase --out padded.bin "$D "`. Exit 0. Bytes after the 52-byte header were exactly `D` followed by ASCII 0x20. Repeating with `"$D"` emitted the original card only. This path admits bytes outside the validated card spelling. The demonstrated CLI path is an argv record. Ordinary line-based input trims its lines.

**Fix and regression.** Require the writer's accepted md1/mk1 spelling to equal the spelling being written, or canonicalize it once before both validation and serialization. Preserve historical reader behavior. Exercise padded and ordinary public cards via argv and the public packer. Assert the wire record itself, in addition to the exit status.

### I18 · Important · The standalone renderer silently ignores an extra operand and all following options

`me-preview render`, `preview/main.go:48`. Pipe `D` to `me-preview render --format svg --out - second-card --mode qr`. Exit 0. Stderr said `mode text+qr` and the 149,986-byte SVG was byte-identical to the default render. With `second-card` removed, the QR-only request reported `mode qr` and wrote 128,606 bytes. Go's flag parser stops at the first positional argument, and the caller never checks the remainder. A user can ship a different engraving layout than requested.

**Fix and regression.** Reject leftover positional arguments after flag parsing and before consuming the card or writing the destination. Test a lone unexpected operand and one followed by a valid mode flag. Both should exit with usage and produce no image. Keep a successful QR-only control.

### I19 · Important · The runtime and build check accept a sidecar whose version command failed

`preview::sidecar_version` in `crates/me-cli/src/preview.rs:111`, `me bundle --preview`, and `scripts/build-preview.sh:37–42`. Use a test double that returns stdout `me-preview 0.13.0\n` and exit 7 for `--version`, and delegates rendering to the real matching binary. Selected with `ME_PREVIEW_BIN`, it rendered a plate and the bundle exited 0. Installed as `target/release/me-preview` in a disposable build tree, it also made `scripts/build-preview.sh --check` print “matches the crate” and exit 0. At runtime even `me-preview0.13.0` with no space was accepted. A correctly formatted successful probe worked, and a genuine 0.12.0 mismatch exited 2.

**Fix and regression.** Require exit 0 and the documented version line on stdout before rendering or approving a build. Preserve stderr as diagnostics. Test failed status with otherwise correct stdout, missing separator, normal success and version mismatch. Have the test double record invocation so the tests can assert that rendering never starts after a failed probe.
