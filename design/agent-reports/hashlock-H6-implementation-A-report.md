codec's `.trim()` is subsumed by its own whitespace filter. So it is a
duplication, not a divergence, and it is unreachable from production. Worth a
follow-up, not a fix inside this task's file list.

`hex::decode(s).is_ok()` → `s.bytes().all(|b| b.is_ascii_hexdigit())`, is applied
